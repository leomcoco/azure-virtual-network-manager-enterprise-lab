# Security Policy

Este repositório é usado para laboratório técnico em Azure.

## Dados sensíveis

Não abra issues ou pull requests contendo:

- subscription ID;
- tenant ID;
- client ID;
- client secret;
- tokens;
- e-mails corporativos;
- nomes de ambientes internos;
- endereços IP sensíveis;
- prints com dados reais.

## Relato de problema

Caso encontre um problema de segurança relacionado ao laboratório, abra uma issue descrevendo o cenário sem incluir dados sensíveis.

## Escopo

Este projeto não deve ser usado diretamente em produção sem revisão de arquitetura, segurança, governança e operação.
